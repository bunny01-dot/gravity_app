# Lottie Animations Directory

This directory is for Lottie animation JSON files.

## Usage

Place Lottie animation files here for use in the app.

## File Requirements

- Format: JSON (.json)
- Max size: 150 KB per file
- Naming: lowercase_with_underscores.json

## Currently

No Lottie animations are required for the initial release.
This directory is prepared for future enhancements.

See `LOTTIE_ANIMATIONS_GUIDE.md` for full implementation details.
